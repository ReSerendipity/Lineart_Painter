04 — 家族规则

成对而不撞款的四条纪律

「各表其主 + 家族统一」：形制、光源、描边、投影四条全部共用；色温（紫夜 / 墨青）与主体（多角度换图卡 / 上色纸）各自保留。

同一底板形制

896×896 画布内圆角方形，圆角 214（约 21%），外圈全透明。

plate 87.5% · rx 214/1024

左上主光源

径向高光圆心固定在 32% / 24%，底部统一压一层暗部渐变。

key light 32% · 24%

香槟金描边

两枚共用同一支金渐变描边（3px），线稿画师侧也用它收边。

rim ic-gold-hi → ic-gold-deep

径向渐变落地影

主体下方统一放一枚椭圆地影，不使用滤镜，保证小尺寸边缘干净。

shadow = radial-gradient ellipse

05 — 底板配色

叠扇金卡，四种底

卡片本体（三张卡叠扇 + 开口腰环）完全一致，只换最外层底板。按你的要求，主用白色底；另留暗夜紫黑、墨青、暮紫三种备选。白底最干净、浅色桌面里金卡最跳；深色底则更沉稳。
